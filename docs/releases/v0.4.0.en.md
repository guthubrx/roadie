# Roadie 0.4.0 — Search, commands and settings

October 14, 2026 · [Français](v0.4.0.md)

This release adds search across visible windows, a command box and a settings
window. It improves tiling and state persistence since version 0.3.0.

## Highlights

- Search results arrive as windows are read. A leading `/` opens commands,
  suggestions and history.
- `/settings` opens the settings window; `/set` reads, changes or resets a value.
  Label sizes are adjustable. Lists remain read-only in this version.
- A persistent spatial tree improves layout, gestures and display transfers.
  Maximization leaves room for the nav rail.
- Daemon-routed commands, atomic writes, validated reloads and hidden-window
  recovery improve reliability.
- Three expensive paths are optimized; these measurements do not describe
  overall interface latency.

## Updating from 0.3.0

`mutableBsp` and `yabai` alias `spatialBsp`. Stage state migrates once, with a
`stages.json.pre-017` backup. In tree mode, use `warp` instead of `layout insert`
or `layout join-with`, and `resize` instead of `layout width`. `layout flatten`
balances the stored tree.

Empty rail clicks are inert by default; `empty_click_hide_active` remains
configurable. Scripts must handle nonzero exit codes. Restore safety runs inside
`roadied run` and `roadied tiler`.
Invalid configuration types and unknown layout strategies are rejected.

The bar and settings require the daemon and `overlay_enabled = true` in
`[experimental.target_mode]`. Application clicks require their explicit settings.
The settings interface is in French.
