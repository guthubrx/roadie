# Roadie 0.9.0 - Arrange with a drag

October 25, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.9.0/docs/releases/v0.9.0.md)

The overview becomes a workbench: drag a desktop, a stage or a window to rearrange
your workspaces without leaving the view.

## Reorder desktops

Drag a desktop chip to the gap you want: above the first desktop, between two desktops
or after the last one. A thin blue line marks the place. On release, desktops are
renumbered as in Mission Control. The moved desktop keeps its stages, windows, name and
pins; no window moves on screen. Shortcuts follow numbers: after dropping "Desktop 2"
first, `roadie desktop focus 1` opens it. The same operation exists on the command
line: `roadie desktop move 2 1`.

## Move a stage or a window

Drag the stage chip of a card between two groups of cards, in its desktop or another
desktop: the stage is inserted there with its windows. Drag a card
onto a card of another stage: the window joins that stage, whose cards get a blue
outline. A simple click still opens the window. The displayed desktop does not change.

## Across displays

The same gestures work between your displays. A desktop dropped on another display
becomes a desktop of that display, and desktops on both displays are renumbered. A
stage or a window joins the target place. Windows move to the other display, hidden
until their desktop and stage are shown there.

[Explore the overview](https://github.com/guthubrx/roadie/blob/v0.9.0/docs/en/overview.md)

## Unique stage names

A named stage exists only once across Roadie, all displays and desktops. Renaming to a
name already in use is refused. A configured workspace now names a single stage.
`roadie state heal` fixes inherited duplicates: the copy with the most windows keeps
the name, other occupied copies become "Name 2", and empty copies become anonymous
again. No window changes stage.

## Fixes

- The window switcher and the overview no longer offer a closed window that its app
  keeps in memory without showing it. Choosing it showed "Action refused by the
  application".
- A window with an imposed size, such as a phone emulator, no longer changes size at
  each stage switch: Roadie remembers a repeated refusal.

## Update and download

Existing configuration and shortcuts are kept. After updating, run `roadie state heal`
to fix any duplicate names. This version requires **macOS 14 or later on Apple
Silicon**. Download `Roadie.dmg` and `Roadie.dmg.sha256` from the
[0.9.0 release](https://github.com/guthubrx/roadie/releases/tag/v0.9.0), then check
the package before opening it:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The package is ad hoc signed and not notarized by Apple.
