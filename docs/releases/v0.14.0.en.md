# Roadie 0.14.0 - Gestures, effects and consolidation

10 November 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.14.0/docs/releases/v0.14.0.md)

This release brings together sessions 142 to 155 since 0.13.0.

## Windows and gestures

- Neighbours follow native edge resizing in spatialBsp and show their future positions during a drag.
- Effects have per-action profiles, curves, duration and spring controls, with a local preview.
- Dragging can show the real window at its destination. A translucent content copy follows the pointer, with adjustable scale and opacity.
- Stage transitions follow their vertical order. Captures have bounded deadlines and focus waits for the transition to finish.
- Modifier gestures move and resize windows, with fixes for successive drops and display changes.
- New windows reach their display before resizing. Cmd+Tab retries and launcher dismissal are more reliable.
- Finder can open or recall a window in the stage under the pointer: `roadie launch /System/Library/CoreServices/Finder.app --here --mouse`.

## Configuration and tools

- `[launcher]` is the public section for launcher settings. `[experimental.target_mode]` still works. When both contain a key, the new section wins. Settings moves only the edited key to the new section; reset removes both forms of that key.
- `roadied --version` and daemon status include the build commit. The version number has one source.
- `roadie completion zsh` completes commands and subcommands. `make coverage` reports test coverage.
- `roadie update check` checks the latest GitHub release only when requested. It neither downloads nor installs an update.
- Two accessibility reads now check the returned type. The event log no longer records every click position.
- Configuration guards also cover optional values and table rows.
- **Apache-2.0** license. Dependencies retain their licenses, included in the app bundle.
- GitHub tests can only be started manually. Pushes, tags and releases do not start CI.

## Installation

**macOS 14 or later, Apple Silicon (arm64).** Download `Roadie.dmg` and `Roadie.dmg.sha256` from the [release](https://github.com/guthubrx/roadie/releases/tag/v0.14.0), then check:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

Drag Roadie to Applications and try to open it. The package is ad hoc signed, without an Apple developer account or notarization. If macOS blocks it, open **System Settings > Privacy & Security > Open Anyway**, then confirm. Grant Accessibility and, for window captures, Screen Recording. [Apple instructions](https://support.apple.com/en-us/102445).

Existing configurations and shortcuts remain usable. User settings are not changed automatically. Old proof slideshows are removed from the current repository after a local archive; guide images remain.
