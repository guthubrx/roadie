# Roadie 0.10.0 - See before you drop

October 25, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.10.0/docs/releases/v0.10.0.md)

In the overview, every drag shows its result before you release: desktops, stages and
windows take their new place live.

## A live preview

While dragging, desktops, stages and cards slide smoothly to make room. The moved item
appears as a translucent ghost at its future place; a desktop is already renumbered.
Nothing follows the pointer: what is shown is what happens on release. A window
dragged onto a stage is surrounded, together with that stage, by a single blue
outline.

## Create by dropping into empty space

A window dropped in the empty area of a desktop creates a new stage there. A window
or a stage dropped below the last desktop of a display creates a new desktop. A
"New stage" or "New desktop" ghost shows what will appear. This also works across
displays.

The overview is now centered vertically.

[Explore the overview](https://github.com/guthubrx/roadie/blob/v0.10.0/docs/en/overview.md)

## Fix

- A window that briefly accepts the requested size and then returns to its own, such
  as the Android emulator, no longer changes size in a loop.

## Update and download

Existing configuration and shortcuts are kept. This version requires **macOS 14 or
later on Apple Silicon**. Download `Roadie.dmg` and `Roadie.dmg.sha256` from the
[0.10.0 release](https://github.com/guthubrx/roadie/releases/tag/v0.10.0), then check
the package before opening it:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The package is ad hoc signed and not notarized by Apple.
