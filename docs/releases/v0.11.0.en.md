# Roadie 0.11.0 - One bar for everything

October 29, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.11.0/docs/releases/v0.11.0.md)

Roadie is now a launcher as well as a window manager. One bar opens apps, windows, files and web pages, and
decides where they go: which stage, which desktop, which side of the screen. It runs your Alfred workflows for
free, without Alfred and without the Powerpack.

![Searching "note" in the bar](https://raw.githubusercontent.com/guthubrx/roadie/v0.11.0/docs/assets/screenshots/launcher-search.png)

## Find everything from one bar

- Apps, windows on every desktop and stage, open documents and browser tabs, files, stages, desktops and displays.
- Firefox, Safari and Chrome bookmarks and history, Roadie settings and System Settings panes.
- System commands (lock, sleep displays, quit all, empty trash…), calculations, typed addresses, web keyword
  searches, `> command` in your terminal, `~/folder` browsing.
- Results learn from your choices and from the active stage. Files you already opened appear at once.
- Results of a workflow, a folder or a file search can be shown as a list, a grid or large tiles (⌘G).

## Say where it goes

- Tab on a row opens its verbs: open in a stage, send a window to a stage, desktop or display, bring here,
  float or tile, recent documents, quit…
- A full phrase does it all at once, in English or French: `safari personal left`.
- While you pick a stage, the real windows move to their future place; Escape puts everything back.
- Multiple selection, undo, projects that reopen a stage as it was, rules suggested after repeated moves.

## Alfred workflows, for free

Workflows already installed in Alfred, or installed with `roadie workflow install`, run in the bar: keywords,
Script Filters, the full object graph, grids, Text, Image and PDF views, Remote buttons and hotkeys (bound in
BetterTouchTool). Out of 102 real workflows, 92 are complete. Alfred's nine themes are included.

[Launcher and workflows guide](https://github.com/guthubrx/roadie/blob/v0.11.0/docs/en/launcher.md)

## Also new

- **English or French, everywhere.** The whole interface follows the macOS language, or the one chosen in
  Settings > General > Interface language. Typed words work in both languages.
- **Always-floating windows by title.** `# Reminder` floats Thunderbird's reminders without floating Thunderbird.
  Add it from the title bar's Window menu or in Settings > Rules. `roadie window explain` tells why a window is
  tiled.
- **Window switcher.** Only the windows, with each app's icon next to the title; Cmd+Tab works between native
  full screen and the ordinary desktop.
- **Settings.** All shortcuts in one place, with BetterTouchTool conflicts; search filters the categories.
- **Rail.** Delete an empty stage from its context menu.

## Fixes

- The bar stays responsive when the Mac is under heavy load.
- After Escape, the keyboard returns to the field that had it.
- Dead keys (tilde, accents) are no longer erased by the bar.

## Update and download

Existing configuration and shortcuts are kept. This version requires **macOS 14 or later on Apple Silicon**.
Download `Roadie.dmg` and `Roadie.dmg.sha256` from the
[0.11.0 release](https://github.com/guthubrx/roadie/releases/tag/v0.11.0), then check the package before opening
it:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The package is ad hoc signed and not notarized by Apple. A workflow runs with Roadie's permissions: only install
workflows you trust. Alfred is a trademark of Running with Crayons Ltd; Roadie is not affiliated with it.
