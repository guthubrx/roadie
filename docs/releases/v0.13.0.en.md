# Roadie 0.13.0 - The zone switcher, your way

October 30, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.13.0/docs/releases/v0.13.0.md)

![Roadie's zone switcher](https://raw.githubusercontent.com/guthubrx/roadie/v0.13.0/docs/assets/screenshots/zone-switcher.png)

A small release after 0.12.0 and its zone switcher (Option+Tab). What 0.12.0 brought:
[release notes](https://github.com/guthubrx/roadie/blob/v0.13.0/docs/releases/v0.12.0.en.md).

## New

- **Shift alone steps back one card**, as in AltTab. During Cmd+Tab or Option+Tab, press Shift and release it
  without any other key: the selection moves back one card. Shift + Tab works as before. Shift does nothing while
  you type a search, or when the profile's shortcut already contains Shift.
- **A click zone count for each app.** By default, each window keeps 3 click zones. In Settings > Switcher >
  "Click zones per app", give an app another count, from 0 to 10: more zones for a spreadsheet, none for Finder.
  Apps not in the list keep the global value. An app set above 0 keeps its zones even when the global value is 0.

  ```toml
  [[switcher.zone_clicks_per_app]]
  app = "com.microsoft.Excel"   # bundle ID or app name
  count = 5
  ```

- **More readable documentation images**: the zone switcher screenshot shows realistic sample windows (booking,
  inbox, calendar, code) instead of grey blocks.

## Updating

Existing configuration and shortcuts are kept; with no line in the new list, nothing changes. This version
requires **macOS 14 or later on Apple Silicon**. Download `Roadie.dmg` and `Roadie.dmg.sha256` from the
[0.13.0 release](https://github.com/guthubrx/roadie/releases/tag/v0.13.0), then check the package:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The package is ad hoc signed and not notarized by Apple.
