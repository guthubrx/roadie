# Roadie 0.5.0 - Live settings and improved search

October 14, 2026 · [Français](v0.5.0.md)

This release brings common configuration tasks into the settings window and
updates typography while the interface stays open. The search and command bar gains Tab completion
and a simpler appearance.

## Highlights

- **Live settings**: valid values apply as you type. Margins and spacing retile
  windows without pressing Return.
- **Built-in editors**: lists, stages, rules and display or stage overrides are
  editable in the window. An advanced editor handles complex structures and
  repairs invalid configuration files.
- **Independent typography**: font sizes per surface and separate font families
  for the input field and suggestions. Open interfaces update without losing input.
- **Search and commands**: Tab completes the selected result or suggestion. The bar stays in
  place, with a thin border and a compact result counter.

## Updating from 0.4.0

Open the bar with the shortcut selected in **Recherche** (Search) settings (`search_hotkey`) or
with `roadie targets search`. The shortcut is customizable.

Existing configuration is preserved. No manual migration is required. Open
`/settings` to adjust spacing, edit stages or choose fonts in **Recherche** (Search).
Display and side overrides retain priority over general margins.

Invalid input keeps the last valid value. Advanced fragments require validation
and explicit saving. Rule actions `layout` and `gap_override`, and `signals.hooks`,
are stored but do not yet have an operational effect.
