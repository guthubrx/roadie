# Roadie 0.5.0 - Réglages immédiats et recherche améliorée

14 octobre 2026 · [English](https://github.com/guthubrx/roadie/blob/main/docs/releases/v0.5.0.en.md)

Cette version permet de régler Roadie depuis sa fenêtre de paramètres et
d'adapter la typographie sans fermer l'interface. La barre de recherche et de commandes gagne une
complétion par Tab et une présentation plus sobre.

## Nouveautés

- **Réglages immédiats** : toute valeur valide s'applique pendant la saisie.
  Les marges et espacements retuilent les fenêtres sans appuyer sur Retour.
- **Éditeurs intégrés** : listes, stages, règles et exceptions par écran ou par
  stage sont modifiables dans la fenêtre. Les rares structures complexes et la
  réparation d'une configuration invalide utilisent un éditeur avancé intégré.
- **Polices indépendantes** : tailles réglables pour chaque surface ; familles
  distinctes pour le champ de saisie et les suggestions. Les interfaces ouvertes
  se mettent à jour sans perdre la saisie.
- **Recherche et commandes** : Tab complète le résultat ou la suggestion sélectionnée. La barre
  garde sa position ; elle affiche une bordure fine et un compteur compact.

## Mise à jour depuis 0.4.0

La barre s'ouvre avec le raccourci défini dans les paramètres de Recherche
(`search_hotkey`) ou avec `roadie targets search`. Ce raccourci est personnalisable.

La configuration existante est conservée. Aucune migration manuelle n'est requise.
Ouvrir `/settings` pour ajuster les espacements, éditer les stages ou personnaliser
les polices dans la catégorie Recherche. Les exceptions par écran ou par côté
gardent leur priorité sur les marges générales.

Une saisie invalide conserve la dernière valeur valide. Les fragments avancés
nécessitent une validation et un enregistrement explicites. Les actions de règle
`layout` et `gap_override`, ainsi que les `signals.hooks`, sont enregistrées mais
n'ont pas encore d'effet opérationnel.
