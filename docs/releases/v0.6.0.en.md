# Roadie 0.6.0 - Windows where you work, a rail you control

October 21, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.6.0/docs/releases/v0.6.0.md)

Keep windows where you work. This release gives you more control over stage
placement and resizing, with targeted interface updates.

## Choose the destination in the rail

Drop a window onto a card to join that stage. Drop above, between or below cards
to create a stage there, on the same display or another one. The new-stage preview
marks the destination before you release the mouse.

Your chosen order stays in place. Scroll when the cards exceed the display height.
Named empty stages keep a visible outline and name. When reordering stages, an
on-screen preview shows their future positions; adjust destination magnetism in
**Settings > Rail**.

## Adjust windows directly

Divider handles between window groups let you change persistent tiling proportions.
Control their visibility in **Tuilage** (Tiling). Native window-edge resizing remains
available, including with JankyBorders decorations. Improved handling of minimum
sizes and delayed application responses helps preserve recent resize gestures.

To remove a window from tiling while keeping it in its stage, use the **Fenêtre**
(Window) menu or `roadie toggle floating`. Repeat the command, or choose “Revenir au tuilage” (Return to tiling), to tile it again.

## Open and find your windows

Without an explicit placement preference, new windows join the current stage on
Roadie's active display, even when the pointer is elsewhere. Successive windows
opened from a terminal therefore stay in that context. Pointer-based and macOS
placement remain available in **Tuilage** (Tiling).

The search and command bar uses native macOS text editing. Up/Down and clicks
select suggestions. Clicking outside dismisses the bar and passes the click through.
Search also recognizes more native labels, including Outlook folders.

## Reusing window data

The rail and other visual components reuse available window snapshots and combine
requests. Thumbnail updates refresh existing cards instead of rebuilding them.
Search and tiling-tree operations avoid repeated traversal. Display reconnection
keeps stages separate and reuses compatible empty slots without replacing the
active stage.

## Updating from 0.5.0

Existing configuration is preserved. If `window_placement.new_apps_target` is
missing or invalid, its default becomes `focused_display`. Explicit `mouse` and
`macos` values stay unchanged. Roadie's double-click maximization is optional and
off by default. Health checks report macOS settings that may conflict with tiling.

Open the bar with your chosen shortcut in **Recherche** (Search), or with
`roadie targets search`.

## Download and validation

Package for **macOS 14 or later on Apple Silicon**. Download `Roadie.dmg` and
`Roadie.dmg.sha256` from [release 0.6.0](https://github.com/guthubrx/roadie/releases/tag/v0.6.0).
Verify the file before opening it:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The distributed package is ad-hoc signed and is not notarized by Apple.
Delivery validation is documented in the
[technical record](https://github.com/guthubrx/roadie/blob/v0.6.0/specs/054-release-060/validation.md).
