# Roadie 0.8.0 - See everything at a glance

October 24, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.8.0/docs/releases/v0.8.0.md)

A global overview shows all your windows, grouped by display, desktop and stage, on
a single page. The window switcher gains five layouts, and hidden windows keep their
size when you use Mission Control.

## A map of all your work

`roadie overview toggle` opens a full-screen view over your blurred wallpaper. Each
desktop is a grid of equally sized cards; a chip shows each window's stage.
Everything fits on one page, without scrolling. Choose **Archipelago**, with
displays as columns, or **Bays**, with displays as bands. The magnifier enlarges the
hovered desktop. Arrow keys move the selection, which starts on the active window;
Enter or a click opens the window in its original context. Previews stay sharp from
one opening to the next.

In **Réglages Roadie > Vue d'ensemble**, set the layout, the magnifier, the
background blur with a live preview, and the selection outline colour and
thickness. Bind the view to a BetterTouchTool gesture, such as a four-finger upward
swipe, or to an optional internal shortcut.

[Explore the overview](https://github.com/guthubrx/roadie/blob/v0.8.0/docs/en/overview.md)

## A switcher that fits you

The window switcher offers five layouts: stage columns, desktop tabs, hierarchical
navigation, grouped sections and a desktop overview. The choice is shared or set per
profile and applies without a restart. The classic grid, shortcuts and release
behaviour remain available.

[Configure the window switcher](https://github.com/guthubrx/roadie/blob/v0.8.0/docs/en/window-switcher.md)

## Fixes

- Mission Control no longer shrinks windows in hidden stages. Roadie pauses while it
  is shown and no longer changes the size of a window it parks.
- The switcher and the overview start from the frontmost window.
- Previews are correct on external displays at one pixel per point.
- `roadie desktop focus next|prev`, as shown in the help, works like
  `roadie desktop next|prev`.

## Update and download

Existing configuration and shortcuts are kept. This version requires **macOS 14 or
later on Apple Silicon**. Download `Roadie.dmg` and `Roadie.dmg.sha256` from the
[0.8.0 release](https://github.com/guthubrx/roadie/releases/tag/v0.8.0), then verify
the package before opening it:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The package is ad hoc signed and is not notarized by Apple.
