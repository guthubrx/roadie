# Roadie 0.11.1 - Workflows that run to the end

October 29, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.11.1/docs/releases/v0.11.1.md)

A corrective release after a full code audit of Roadie 0.11.0. No new feature; your configuration stays as it is.
New in 0.11.0: [release notes](https://github.com/guthubrx/roadie/blob/v0.11.1/docs/releases/v0.11.0.en.md).

## Fixes

- **Workflow actions run to the end.** Run Script, Run NSAppleScript, automation tasks and Run Shortcut were
  stopped after 10 seconds (30 seconds for a shortcut). They now run to completion, as in Alfred: a workflow that
  downloads or converts a file no longer fails with "timed out". Script Filters keep their 10-second limit while
  you type.
- **System commands wait for you.** The bar's system commands wait up to 10 minutes: you have time to type your
  password for "Rebuild Spotlight index" or to confirm a log out. A failure now shows a notification; cancelling
  stays silent.
- **Settings show only values Roadie applies.** A key written without a value, then again with a value, is now
  refused as a duplicate, as when the file is written.
- **Faster Firefox tab lookup.** Choosing a Firefox tab now takes time proportional to the window's contents.

## Update

Existing configuration and shortcuts are kept. This version requires **macOS 14 or later on Apple Silicon**.
Download `Roadie.dmg` and `Roadie.dmg.sha256` from the
[0.11.1 release](https://github.com/guthubrx/roadie/releases/tag/v0.11.1), then check the package before opening
it:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The package is ad hoc signed and not notarized by Apple. A workflow runs with Roadie's permissions: only install
workflows you trust. A workflow action that never ends is no longer stopped, as in Alfred.
