# Roadie v0.3.0 Release Notes

Roadie v0.3.0 is the modular runtime and mutable BSP release.

The main change is architectural: Roadie can now run as separate components
instead of a single all-or-nothing daemon. That makes the system easier to
observe, easier to debug, and prepares Roadie for companion-mode usage beside
another window manager.

The second major change is layout behavior: the BSP work is now much closer to
the yabai workflow. Roadie can keep a persistent BSP tree, move and warp windows
inside it, preserve observed split ratios, and handle mouse swaps without
unexpected reflow.

## Highlights

- Modular runtime with separate `tiler`, `rail`, `border`, `focus-mouse`,
  `titlebar-menu`, `target-mode`, and `restore-safety` components.
- Component locks, component status, health checks, and per-component logs.
- `./scripts/start-modular` for the full modular profile.
- `roadie query components` and improved `roadie daemon health` for modular
  observability.
- Persistent BSP tree support for spatial/yabai-like tiling experiments.
- Mutable BSP tree manipulation: move, warp, resize, insert, swap, and
  `layout toggle-split`.
- `yabai` now maps to `mutableBsp` in Roadie configuration and CLI aliases.
- New windows split 50/50 instead of inheriting arbitrary macOS-created frames.
- Mouse drag/swap behavior is stabilized across both monolithic and modular
  modes.
- Display reconnect and state-audit stability improvements.
- README positioning tables expanded in English and French.

## Modular Runtime

The modular runtime is useful immediately because each component has a clear
runtime boundary:

- `tiler` owns layout application;
- `rail` owns the stage rail;
- `border` owns the focus border;
- `focus-mouse` owns focus-follows-mouse;
- `titlebar-menu` owns title-bar gestures and menus;
- `target-mode` owns keyboard targets and grids;
- `restore-safety` owns restore snapshots.

This makes failures and logs easier to isolate. It also sets up a future mode
where Roadie can be used as a companion layer: for example, stages plus rail,
focus border, target mode, or restore safety beside yabai, AeroSpace, or another
window manager.

The current `start-modular` script starts the full component set, including the
tiler. Stage-only and overlay-only startup profiles are intentionally treated as
future work.

## Mutable BSP

The goal is not to clone yabai, but to preserve the part of the workflow that
matters most: a default BSP structure that the user can then reshape.

Roadie v0.3.0 improves that in several ways:

- persistent BSP tree state for spatial BSP layouts;
- mutable BSP operations for keyboard-driven tree manipulation;
- split-ratio preservation after manual moves/resizes;
- stable mouse drag previews and swaps;
- command-sourced layout intents that are not incorrectly invalidated by small
  but intentional panes.

## Known Limits

- The DMG is ad-hoc signed, not Developer ID signed, and not notarized.
- Companion-mode profiles are not yet first-class commands.
- Roadie still avoids SIP-disabling/private write APIs, so it does not control
  native macOS Spaces like yabai can.

# Notes de release Roadie v0.3.0

Roadie v0.3.0 est la release du runtime modulaire et du BSP mutable.

Le changement principal est architectural : Roadie peut maintenant tourner en
composants separes plutot qu'en daemon unique. Cela rend le systeme plus
observable, plus simple a debugger, et prepare un usage compagnon a cote d'un
autre window manager.

Le deuxieme axe est le layout : le BSP se rapproche du workflow yabai. Roadie
peut conserver un arbre BSP persistant, deplacer et warp des fenetres dans cet
arbre, conserver les ratios observes, et stabiliser les swaps a la souris.

## Points forts

- Runtime modulaire avec composants `tiler`, `rail`, `border`, `focus-mouse`,
  `titlebar-menu`, `target-mode` et `restore-safety`.
- Locks de composants, statut, health checks et logs par composant.
- `./scripts/start-modular` pour le profil modulaire complet.
- `roadie query components` et `roadie daemon health` adaptes au modulaire.
- Arbre BSP persistant pour les experimentations de tiling spatial proches de
  yabai.
- Manipulation BSP mutable : move, warp, resize, insert, swap et
  `layout toggle-split`.
- L'alias `yabai` pointe maintenant vers `mutableBsp`.
- Les nouvelles fenetres split 50/50 au lieu d'heriter d'une frame macOS
  arbitraire.
- Drag/swap souris stabilise en mode monolithique et modulaire.
- Ameliorations de stabilite sur reconnexion d'ecran et audit d'etat.

## Limites connues

- Le DMG est signe ad-hoc, pas signe Developer ID, et pas notarized.
- Les profils companion-mode stage-only ou overlay-only ne sont pas encore des
  commandes publiques stables.
- Roadie ne pilote pas les Spaces macOS natifs via APIs privees.
