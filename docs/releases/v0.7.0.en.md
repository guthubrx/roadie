# Roadie 0.7.0 - A window switcher for your workspaces

October 23, 2026 · [Français](https://github.com/guthubrx/roadie/blob/v0.7.0/docs/releases/v0.7.0.md)

Switch to a window and return to its desktop, stage and display. This release
introduces a switcher built for Roadie and makes settings easier to navigate.

## Find the right window

Browse with all four arrow keys or the mouse. Search by application, title,
stage or desktop. A thumbnail grid sits beside a larger preview; icon and list
views provide two other layouts. Confirming a window opens its original context
without moving it into the current stage. Switcher actions also let you close,
minimize, restore or enlarge the selected window.

## Choose how you switch

In **Réglages Roadie > Sélecteur**, create up to nine profiles for a display, desktop,
stage or application. Releasing the keys can activate the window, keep the
switcher open or enter search. Filters, sorting and appearance are set per profile.

Record a combination by pressing its keys and let Roadie or BetterTouchTool
handle it. CLI commands remain available for Karabiner and other tools. For
example, `roadie switcher cycle --hold cmd` lets an external shortcut control
the switcher. Roadie reserves no global opening shortcut by default, so you
choose the combination.

[Configure the switcher and its shortcuts](https://github.com/guthubrx/roadie/blob/v0.7.0/docs/en/window-switcher.md)

## Clearer settings

Categories share compact, aligned forms. Rules expand individually, full-width
tabs show the active section clearly, and help panels scroll to keep their text
accessible. Fields and menus follow your chosen font size. Valid changes still
apply as you type.

## Give a window the whole space

`roadie toggle fullscreen` enlarges the window and hides the rail, including on
hover. This mode stays within the Roadie workspace rather than entering native
macOS fullscreen. Repeat the command to restore the layout. Maximization that
keeps the rail remains available through `roadie toggle maximize`.

## Update and download

Existing configuration and shortcuts are preserved. This release requires
**macOS 14 or later on Apple Silicon**. Download `Roadie.dmg` and
`Roadie.dmg.sha256` from [release 0.7.0](https://github.com/guthubrx/roadie/releases/tag/v0.7.0),
then check the package before opening it:

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

The package is ad hoc signed and is not notarized by Apple.
