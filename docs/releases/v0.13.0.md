# Roadie 0.13.0 - Le sélecteur de zones à votre main

30 octobre 2026 · [English](https://github.com/guthubrx/roadie/blob/v0.13.0/docs/releases/v0.13.0.en.md)

![Sélecteur de zones de Roadie](https://raw.githubusercontent.com/guthubrx/roadie/v0.13.0/docs/assets/screenshots/fr/zone-switcher.png)

Petite version qui suit la 0.12.0 et son sélecteur de zones (Option+Tab). Nouveautés de la 0.12.0 :
[notes de version](https://github.com/guthubrx/roadie/blob/v0.13.0/docs/releases/v0.12.0.md).

## Nouveautés

- **Maj seule recule d'une carte**, comme dans AltTab. Pendant Cmd+Tab ou Option+Tab, appuyez sur Maj puis
  relâchez-la sans autre touche : la sélection revient d'une carte. Maj + Tab fonctionne comme avant. Maj est sans
  effet pendant la saisie d'une recherche, ou si le raccourci du profil contient déjà Maj.
- **Un nombre de zones de clics pour chaque application.** Par défaut, chaque fenêtre garde 3 zones de clics. Dans
  Paramètres > Sélecteur > « Zones de clics par application », donnez un autre nombre à une application, de 0 à 10 :
  plus de zones pour un tableur, aucune pour le Finder. Les applications absentes de la liste gardent la valeur
  globale. Une application réglée au-dessus de 0 garde ses zones même si la valeur globale vaut 0.

  ```toml
  [[switcher.zone_clicks_per_app]]
  app = "com.microsoft.Excel"   # identifiant ou nom de l'application
  count = 5
  ```

- **Images de documentation plus lisibles** : la capture du sélecteur de zones montre des fenêtres d'exemple
  réalistes (réservation, boîte de réception, agenda, code) au lieu de blocs gris.

## Mise à jour

La configuration et les raccourcis existants sont conservés ; sans ligne dans la nouvelle liste, rien ne change.
Cette version nécessite **macOS 14 ou ultérieur sur Apple Silicon**. Téléchargez `Roadie.dmg` et
`Roadie.dmg.sha256` depuis la [release 0.13.0](https://github.com/guthubrx/roadie/releases/tag/v0.13.0), puis
vérifiez le paquet avant de l'ouvrir :

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

Le paquet est signé ad hoc et n'est pas notarisé par Apple.
