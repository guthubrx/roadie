# Roadie 0.11.1 - Des workflows qui vont jusqu'au bout

29 octobre 2026 · [English](https://github.com/guthubrx/roadie/blob/v0.11.1/docs/releases/v0.11.1.en.md)

Version corrective après un audit complet du code de Roadie 0.11.0. Aucune nouvelle fonction ; votre configuration
reste telle quelle. Nouveautés de la 0.11.0 : [notes de version](https://github.com/guthubrx/roadie/blob/v0.11.1/docs/releases/v0.11.0.md).

## Corrections

- **Les actions des workflows vont jusqu'au bout.** Run Script, Run NSAppleScript, les tâches d'automatisation et
  Run Shortcut étaient arrêtés après 10 secondes (30 secondes pour un raccourci). Ils vont maintenant à leur terme,
  comme dans Alfred : un workflow qui télécharge ou convertit un fichier n'échoue plus sur « délai dépassé ». Les
  Script Filters gardent leur limite de 10 secondes pendant la frappe.
- **Les commandes système vous attendent.** Les commandes système de la barre attendent jusqu'à 10 minutes : vous
  avez le temps de taper le mot de passe de « Reconstruire l'index Spotlight » ou de confirmer une fermeture de
  session. Un échec s'affiche dans une notification ; une annulation reste silencieuse.
- **Les Paramètres montrent seulement les valeurs appliquées.** Une clé écrite sans valeur, puis de nouveau avec une
  valeur, est refusée comme doublon, comme à l'écriture du fichier.
- **Choix d'un onglet de Firefox plus rapide.** Le temps de recherche suit maintenant le contenu de la fenêtre.

## Mise à jour

La configuration et les raccourcis existants sont conservés. Cette version nécessite **macOS 14 ou ultérieur sur
Apple Silicon**. Téléchargez `Roadie.dmg` et `Roadie.dmg.sha256` depuis la
[release 0.11.1](https://github.com/guthubrx/roadie/releases/tag/v0.11.1), puis vérifiez le paquet avant de
l'ouvrir :

```bash
shasum -a 256 -c Roadie.dmg.sha256
```

Le paquet est signé ad hoc et n'est pas notarisé par Apple. Un workflow tourne avec les droits de Roadie :
n'installez que ceux que vous connaissez. Une action de workflow qui ne se termine jamais n'est plus arrêtée,
comme dans Alfred.
