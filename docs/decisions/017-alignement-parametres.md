# 017 - Alignement commun des paramètres
Date : 23 octobre 2026. Statut : accepté dans la correction 058.

Les formulaires existants reposent sur plusieurs dispositions indépendantes.
Une ligne commune fixe les colonnes selon largeur et police, mesure leur hauteur
et garde une place pour le rétablissement. Les formulaires simples, collections
et profils utilisent cette même ligne. À faible largeur, le repli vertical est
uniforme. L'aide longue défile dans une zone bornée.

Les contrôles, la persistance et les raccourcis sont conservés. Le dépliage des
entrées n'est qu'un état de présentation. La géométrie locale est constante par
ligne ; aucun accès AX ou disque supplémentaire n'est ajouté à la mise en page.
