# Essai 089

1. `roadie workflow list --hotkeys` : raccourcis d'Audio Switcher avec leur commande.
2. `roadie workflow run <Audio Switcher> <uid>` : la sortie audio change, notification affichée.
3. `roadie workflow tasks update` : les tâches d'automatisation sont téléchargées ; la fiche d'un
   workflow qui en utilise passe à « complet ».
4. Capslock + F sur un fichier, Tab : verbes « Workflow : … » si un workflow agit sur ce type.
5. Saisie sans résultat : les recherches de repli des workflows en bas de liste.
6. `roadie workflow check …` sur le corpus : au moins 90 % avec une entrée complète.
