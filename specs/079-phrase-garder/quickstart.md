# Essai 079

1. Capslock + F, `fire perso gauche` : ligne « Ouvrir Firefox dans Perso, à gauche » en tête ;
   Retour.
2. `fire perso left` : même ligne.
3. Sur cette ligne, ⌘S, taper `fp`, Retour. Ensuite `fp` met l'action en tête.
4. Dans l'étape Garder, ⌘C copie `roadie launch '/Applications/Firefox.app' --stage 'Perso'
   --position left` ; la coller dans un terminal fait la même chose.
