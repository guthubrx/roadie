# Essai 082

1. Un PDF ouvert dans Aperçu, dans une stage cachée. Capslock + F, une partie de son nom : ligne
   dans « Documents et onglets » ; Retour : la stage s'affiche, Aperçu devant.
2. Chrome avec plusieurs onglets : taper un mot du titre d'un onglet en arrière-plan ; Retour
   sélectionne l'onglet (macOS demande une fois l'autorisation d'automatisation).
