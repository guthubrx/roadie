# Contrats inter-lots 056

RoadieCore (public Equatable Codable Sendable, init avec défauts) :
`WindowSwitcherConfig`: enabled:Bool=true, style:String="thumbnails" (thumbnails/icons/list), autoSize:Bool=true, thumbnailWidth:Double=220 (120...400), fontSize:Double=16 (10...32), fontFamily:String="system", preview:Bool=true, excludedBundles:[String]=[], shortcuts:[WindowSwitcherShortcutConfig] max9.
`WindowSwitcherShortcutConfig`: id:String="all", name:String="Toutes les fenêtres", hotkey:String="ctrl+alt+tab", scope:String="all" (stage/desktop/display/application/all), releaseAction:String="focus" (focus/stay), sortOrder:String="recent" (recent/title/stage), includeMinimized:Bool=true, includeHidden:Bool=true, includeFullscreen:Bool=true, onePerApp:Bool=false.
`RoadieConfig.switcher:WindowSwitcherConfig`; TOML [switcher] et [[switcher.shortcuts]], clés snake_case. Décodage rétrocompatible. Éditeur collection intégré, pas fichier config imposé.

RoadieDaemon modèle (internal, tests @testable) :
`WindowSwitcherEntry:Identifiable,Equatable,Sendable` : window:WindowSnapshot, scope:StageScope?, displayName:String, desktopName:String, stageName:String, isMinimized:Bool, isHidden:Bool, isFullscreen:Bool, isAvailable:Bool ; id:WindowID calculé. init explicite avec bool défauts.
`WindowSwitcherContext:Equatable,Sendable` : focusedWindowID:WindowID?, displayID:DisplayID?, desktopID:DesktopID?, stageID:StageID?, bundleID:String? ; init avec défauts nil. Vérifier noms types RoadieCore avant implémentation, DesktopID/StageID existent.
`WindowSwitcherModel` : init(entries:[WindowSwitcherEntry], profile:WindowSwitcherShortcutConfig, context:WindowSwitcherContext, recentIDs:[WindowID]=[], excludedBundles:[String]=[]). `matches:[WindowSwitcherEntry]`, `selected:WindowSwitcherEntry?`, `query:String`, `mutating next(backwards:Bool=false)`, `mutating select(id:WindowID)`, `mutating search(_ query:String)`, `mutating remove(id:WindowID)`. Initialiser sélection à la fenêtre précédente si au moins deux, sinon unique. Aucun effet de focus dans le modèle.
`WindowSwitcherFocusHistory` thread-safe, shared, `observe(_ id:WindowID?)`, `recentIDs:[WindowID]`, max512, pas d'I/O ; intégrer observation dans publication du snapshot côté parent, ignorer nil/doublons.

RoadieDaemon service (internal sauf API controller) :
`WindowSwitcherService` init(service:SnapshotService=SnapshotService()), `@MainActor func load() async -> (entries:[WindowSwitcherEntry], context:WindowSwitcherContext)`, `func activate(_ entry:WindowSwitcherEntry) -> WindowCommandResult`, `func perform(_ action:WindowSwitcherAction,on entry:WindowSwitcherEntry) -> WindowCommandResult`.
`enum WindowSwitcherAction:String,CaseIterable { case close,minimize,hideApp,quitApp,maximize,fullscreen }`.
Activation rejoint écran/bureau/stage propriétaires, jamais assign/summon et jamais signet temporaire. Relire cible/liveness avant mutation ; mode réduit restauré ; erreurs explicitement rapportées. Réutiliser placement de signet. L'agent service peut ajouter helper AX isolé dans RoadieAX pour inventaire sélection/close/minimize, sans changer le provider du tiler ; travail AX hors MainActor lors de load et borné par PID. Ne pas inventer des états minimisés à partir de isOnScreen.

RoadieDaemon UI : `@MainActor public final class WindowSwitcherController`, init(service:SnapshotService=SnapshotService()), public start(), stop(), show(profileID:String?=nil), next(backwards:Bool=false), accept(), cancel(). Le parent raccorde main et CLI (notification dédiée admise).
Le controller utilise RoadieConfig().switcher via ConfigReloadService, les modèles ci-dessus, WindowSwitcherService et RailThumbnailStore (internal accessible). Si cache partagé parent pas prêt, utiliser injection optionnelle/paramètre avec défaut pour RailThumbnailStore. Pas de second timer permanent : observer réglages ; timer de rafraîchissement éventuel uniquement panel ouvert.
Trois styles, champ natif NSSearchField/NSTextField, scroll, libellés contexte, aperçu image sans focus, boutons/menu actions. Focus/placement seulement à validation/action. Raccourcis press/repeat/release fiables, Maj inverse, Échap annule ; mode recherche persistant autorisant relâchement et édition macOS sans avaler Cmd+A/C/V. Fermer au clic extérieur sans manger clic. En cas collision raccourci rapporter au journal, ne jamais désactiver un autre outil automatiquement. Afficher chargement si acquisition, annulation avant retour async ne réouvre pas panel. Capture vignettes bornée, fallback immédiat icône. Accessibilité labels/buttons respectée.
