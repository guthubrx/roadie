# Essai 092

1. `roadie workflow list` : System Settings Explorer n'indique plus « manque : userinterface.grid ».
2. Capslock + F, taper `sse`, Retour : une grille de volets (7 colonnes) s'ouvre, Wi-Fi ou la
   tuile présélectionnée choisie.
3. ← → ↑ ↓ : la sélection se déplace ; taper `blue` : seules les tuiles Bluetooth restent.
4. Retour sur Wi-Fi : Réglages Système ouvre le volet Wi-Fi.
5. Rouvrir, choisir « General » (catégorie) : une seconde grille montre ses volets.
6. Échap ferme la barre.
