# Modèle transitoire
Session : contexte de départ, source exclue, fenêtres initiales et observées, identifiants touchés, permis révocable et dispatcher. États : inactif → aperçu → restauration/clôture → inactif. Une nouvelle commande invalide tout l’état ancien. Aucun champ persistant d’aperçu.
Configuration : TilingConfig.liveDragPreview ↔ tiling.live_drag_preview, booléen vrai par défaut.
