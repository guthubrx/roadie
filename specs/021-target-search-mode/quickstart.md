# Quickstart : mode recherche
1. `make install && make restart`.
2. Bluejay au premier plan, Verr. Maj (hyper) + F : barre de saisie en bas, lettres affichées.
3. Taper `subscr` : « Subscriptions » en vert ; Retour ouvre Abonnements.
4. Taper une partie d'un titre de vidéo : la carte est trouvée ; Cmd-Retour l'ouvre dans un nouvel onglet (si l'app le gère), Maj-Retour fait un clic droit.
5. `*` affiche tout ; `?` montre les propriétés.
6. Changer `search_hotkey` dans `~/.config/roadies/roadies.toml` : effet en 2 s sans redémarrage ; `grep search_hotkey ~/.roadies/events.jsonl | tail -1`.
