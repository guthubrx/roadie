# Essai 077

1. Capslock + F, `rapport` : section Fichiers avec icônes et dossiers.
2. Espace puis `rap` : seulement des fichiers.
3. Retour sur un PDF déjà ouvert dans Aperçu : Roadie va à sa fenêtre, dans sa stage.
4. Tab sur un fichier : Ouvrir dans…, Amener ici, Montrer dans le Finder, Aperçu, Copier le chemin.
5. ⌘C sur la ligne : le chemin est copié ; ⌘Y : Quick Look.
6. `roadie launch ~/Documents/x.txt --stage Perso` : le fichier s'ouvre dans Perso.
