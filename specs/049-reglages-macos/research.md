# Recherche - 049

- TrellisWM 0.9.5 : étape « Turn off what gets in the way ».
- Préférences relevées sur la machine de l'utilisateur (macOS 26.2), domaine
  `com.apple.WindowManager` : `GloballyEnabled = 0`, `EnableTilingByEdgeDrag = 0`,
  `EnableTopTilingByEdgeDrag = 0`, `EnableStandardClickToShowDesktop = 0`.
- Réglage écarté : « Les écrans disposent d'espaces distincts » (`com.apple.spaces
  spans-displays`). Roadie fonctionne avec la valeur par défaut chez l'utilisateur ; aucun
  défaut connu ne lui est attribué.
- Réglage écarté : maintien de ⌥ pendant le glisser (`EnableTilingOptionAccelerator`) :
  action délibérée de l'utilisateur.
- Limite : le défaut macOS d'une clé absente vient de la version affichée dans Réglages
  Système ; il n'est pas documenté par Apple et peut changer.
