# Essai 075

1. Capslock + F, `fire`, tenir ⌘ : le détail devient « ⌘ ↩ Ouvrir dans une nouvelle stage ».
   ⌘ Retour : Firefox s'ouvre dans une nouvelle stage, Roadie y va.
2. Capslock + F, `out`, ⌥ Retour : la fenêtre Outlook arrive dans la stage affichée.
3. Capslock + F, `chat noir`, ⌃ Retour : recherche Google « chat noir ».
4. Capslock + F, `s` : les lignes portent ⌘1, ⌘2… ; ⌘2 lance la deuxième.
5. Sur une fenêtre, Capslock + Maj + F : la barre montre ses verbes. `roadie targets actions`
   fait de même.
6. `fire` puis → : verbes de Firefox.
7. Verbes d'une fenêtre Firefox : « Toujours faire flotter Firefox » ; toutes les fenêtres
   Firefox flottent ; `~/.config/roadies/roadies.generated.toml` contient
   `affinity-app-org-mozilla-firefox` avec `floating = true`. « Retirer la règle » : retour au
   tuilage.
