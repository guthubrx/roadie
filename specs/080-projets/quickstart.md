# Essai 080

1. Nommer une stage « Essai » avec deux fenêtres (Aperçu sur un PDF, TextEdit sur un texte).
2. Capslock + F, `essai`, Tab, « Enregistrer comme projet » (ou `roadie project save Essai`).
3. Fermer les deux fenêtres ; `roadie project open Essai` : les deux reviennent dans « Essai »,
   comme avant.
4. `roadie project list` ; `roadie project delete Essai`.
