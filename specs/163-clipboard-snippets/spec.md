# Spec 163 — Historique presse-papiers sécurisé & Snippets / Expandeur local (Lot 6)

## Objectif

Enrichir le lanceur et la CLI Roadie de deux capacités 100 % locales, désactivables dans les réglages et conçues pour la confidentialité par défaut :

1. **Historique du presse-papiers local et sécurisé (`[clipboard]`)**
   - Stockage local uniquement dans `~/.roadies/clipboard.json` (isolé via `TestEnvironment` en test) créé atomiquement avec permissions strictes `0o600` (jamais lisible par d'autres utilisateurs même transitoirement).
   - **Filtrage strict de confidentialité (`ClipboardSecurityFilter`)** : tout contenu portant un type `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword`, `com.typeit4me.clipping`, `de.petermaurer.TransientPasteboardType` ou issu d'une application exclue (`clipboard.excluded_bundles`, contenant par défaut KeePassXC, 1Password, Bitwarden, Trousseau d'accès, LastPass, Dashlane) est immédiatement ignoré et n'est **jamais** stocké ni journalisé.
   - Déduplication exacte (remonte en tête en conservant l'état épinglé), taille maximale bornée (`max_items` dans `10...2000`, défaut `200`, éviction prioritaire des entrées non épinglées), rétention en jours (`retention_days` dans `1...90`, défaut `7`), plafond par entrée (`64 Kio` UTF-8), zéro texte copié dans `EventLog`.
   - Recherche dans le lanceur via `cb …` / `clipboard …` (Retour recopie l'entrée) et CLI daemon-routée `roadie clipboard list|search|copy|pin|delete|clear [--all] [--json]`.
   - Aucun timer ni polling lorsque `clipboard.enabled = false`.

2. **Snippets & Expandeur local (`[snippets]`)**
   - Snippets nommés (`[[snippets.items]]` : `keyword`, `title`, `body`) éditables en TOML et dans **Paramètres > Recherche > Snippets**.
   - Expansion dynamique en une passe (sans ré-expansion récursive du contenu du presse-papiers) : `{date}`, `{time}`, `{datetime}`, `{clipboard}`, `{cursor}` (renvoie le texte final et le décalage curseur depuis la fin).
   - Recherche dans le lanceur via `snip …` / `snippet …` (Retour étend et copie dans le presse-papiers) et CLI `roadie snippet list|expand KEYWORD [--copy] [--json]`.
   - Auto-expansion clavier optionnelle (`snippets.auto_expand = false` par défaut) : aucun moniteur clavier tant que `enabled && auto_expand` n'est pas vrai ; ignore systématiquement la saisie sécurisée (`IsSecureEventInputEnabled()`) et les applications exclues.

## Réglages TOML & Paramètres

- `[clipboard]`: `enabled = true`, `max_items = 200`, `retention_days = 7`, `excluded_bundles = [...]`
- `[snippets]`: `enabled = true`, `auto_expand = false`, `[[snippets.items]]` (`keyword`, `title`, `body`)
