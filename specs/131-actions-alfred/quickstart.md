# Essai rapide 131

1. Barre (Capslock + F), taper un nom de fichier, Tab : « Copier vers… », « Déplacer vers… », « Ouvrir avec… »,
   « Envoyer par e-mail », « Mettre à la corbeille », « Créer un alias », « Informations », « Étiquette… ».
2. Sélectionner un texte dans une application, Capslock + Maj + F : verbes du texte (copier, chercher sur le web,
   extraire les adresses…).
3. Taper `onglet` ou le titre d'un onglet ouvert, Tab : « Fermer l'onglet », « Copier l'adresse », « Nouvelle fenêtre ».
4. Paramètres > Recherche : choisir l'effet de ⌘, ⌥ et ⌃ + Retour ; vérifier l'annonce sur la ligne.
5. Workflow avec Commande système, Commande Musique, Dictionnaire ou Applications ouvertes : il tourne en entier.
6. Barre : `menu export` (menus de l'application active), `mode sombre`, `capture`, `raccourci <nom>`.
7. Barre : `apps` (grille par catégorie), `symbols heart` (navigateur SF Symbols).
8. Paramètres > Recherche : style des vues de workflow, thèmes Glassy Dark et Glassy Light.
9. Vue Texte d'un workflow avec un tableau Markdown : colonnes alignées.

Tests : `scripts/test --no-parallel --filter Spec131`, puis la suite complète.
